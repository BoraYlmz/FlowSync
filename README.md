✔ Yetkilendirme (Auth)  
✔ Kullanıcı yönetimi

## <h2 id="english">English</h2> 

### 🧠 About the Project
**FlowSync** is a web application combining CRM with personnel tracking.  
In current **V1.0** release:

✔ Authorization (Auth)  
✔ User management  
✔ Meeting creation & tracking  

📌 Planned future features:

- In-app **email**  
- **Messaging / chat**  
- **Calendar & events**  
- **Todo / planner**  
- Personnel status & productivity reports  

Built with React (frontend) and Python Flask (backend). Database and environment variables are listed in `.env`.

---

### 📦 Features
- JWT / role-based authorization  
- User & meeting CRUD  
- Flexible frontend structure  
- API-first approach
